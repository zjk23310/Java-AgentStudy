# 思路
这一题不难，
在介绍这题答案之前，官解还给出了一些很有趣的答案思路：
1.使用集合存储数字，当集合中没有遍历数字时加入，有则删除最后便是
2.使用集合存储所有出现的数字，由于只有一个单个数字，所以将集合所有元素相加减去遍历表中所有元素就是所求数字
说实话，我不是特别喜欢官方的答案，但是也学习到了新的知识，异或运算
任何数和 0 做异或运算，结果仍然是原来的数，即 a⊕0=a。 任何数和其自身做异或运算，结果是 0，即 a⊕a=0。 异或运算满足交换律和结合律，即 a⊕b⊕a=b⊕a⊕a=b⊕(a⊕a)=b⊕0=b。
