| 容器/场景           | 比较器传入方式       | 关键点                                          |
| --------------- | ------------- | -------------------------------------------- |
| set / map       | **模板参数**      | 比较器是容器类型的一部分，必须在编译期确定。                       |
| priority_queue  | **模板参数**      | 默认为大顶堆（`std::less`），小顶堆需显式使用 `std::greater`。 |
| vector / list 等 | **算法/成员函数参数** | 最灵活，容器本身不自动排序，需要调用 `sort` 等算法。               |
| unordered_      | 不支持排序         | 基于哈希，无法通过比较器定义顺序。                            |

自定义比较器示例：
```c++
struct DescendingCompare {
    bool operator()(int a, int b) const {
        return a > b; // 注意是大于号，代表降序
    }
};
// 对于 set
std::set<int, DescendingCompare> mySet; 
// 对于 map，比较器作用于键（Key）
std::map<int, std::string, DescendingCompare> myMap;
```
