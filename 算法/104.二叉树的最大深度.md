# 初见：
这一题比较简单，看到的第一眼就想到了递归，递归左右子树，如果递归到空指针返回0，否则返回左右字数的最大值加一就好。
```cpp
class Solution {
public:
    
    int maxDepth(TreeNode* root) {
     if(root==nullptr)
        return 0;
     int Lref=maxDepth(root->left);
     int Rref=maxDepth(root->right);
         return max(Lref,Rref)+1;
    }
};
```
