# Leetcode官解
## 反序中序遍历
使用反序中序遍历，创建了一个局部变量sum，先遍历右子树（找到比自己大的和），之后遍历左字数就好了，这一题这样看来确实是很简单很简单的，我都不知道我是怎么想的
```cpp
int sum=0;
TreeNode * converBST(TreeNode * root)
{
if(root!=nullptr)
{
converBST(root->right);
sum+=root->val;
root->val=sum;
converBST(root->left);
}
return root


}
```
