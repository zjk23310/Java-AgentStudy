#算法/字符串

# 题目

**14. 最长公共前缀**

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**
```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**
```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**约束：**
- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

---

# 初见思路

最直观的想法：**纵向扫描**。

以 `["flower","flow","flight"]` 为例：

```
f  l  o  w  e  r
f  l  o  w
f  l  i  g  h  t
── ── ──
fl     ↑ 第3列 o≠i，停！
```

- 第 1 列：三个都是 `f` → 匹配，加入答案
- 第 2 列：三个都是 `l` → 匹配，加入答案
- 第 3 列：`o` vs `i` → 不匹配，停止

结果：`"fl"`

**关键**：先找到最短的字符串长度（因为公共前缀不可能比最短的还长），然后逐列比较所有字符串的同一位置字符是否相同。

---

# 我的解法

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        // ① 找最短字符串长度（公共前缀的上限）
        int min_size = INT_MAX;
        for (string s : strs)
            min_size = min(min_size, (int)s.size());

        // ② 逐列比较
        string ans = "";
        bool back = false;
        for (int i = 0; i < min_size; ++i) {
            char ch = strs[0][i];  // 以第一个字符串的第 i 个字符为基准
            for (string s : strs)
                if (s[i] != ch) {
                    back = true;
                    break;
                }
            if (back == true)
                break;
            ans += ch;  // 所有字符串在第 i 列都相同 → 加入答案
        }
        return ans;
    }
};
```

**时间复杂度**：O(n × m)，n 是字符串个数，m 是最短字符串长度

**空间复杂度**：O(1)（不计答案字符串）

**思路解读**：

这是一个**纵向扫描**（Vertical Scanning）的解法：

```
第 i 列：取 strs[0][i] 作为基准字符 ch
  → 遍历所有字符串，看第 i 个字符是否都等于 ch
  → 是 → ans += ch，继续下一列
  → 否 → break，返回当前 ans
```

`back` 布尔变量充当"跳出两层循环"的信号——内层循环发现不匹配时设为 `true`，外层循环检查到后立即终止。

> [!tip] 为什么要先找 min_size？
> 公共前缀不可能比最短的字符串还长。比如 `["ab", "a"]`，最长公共前缀最多只有 1 个字符。先算出 `min_size` 避免越界访问。

# 官方解法

## 方法一：横向扫描

依次比较前两个字符串，得到公共前缀 `LCP`，再拿 `LCP` 和第三个字符串比较，以此类推。

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";

        string prefix = strs[0];
        for (int i = 1; i < strs.size(); ++i) {
            prefix = lcp(prefix, strs[i]);
            if (prefix.empty()) break;  // 提前终止
        }
        return prefix;
    }

    // 求两个字符串的最长公共前缀
    string lcp(const string& s1, const string& s2) {
        int len = min(s1.size(), s2.size());
        int index = 0;
        while (index < len && s1[index] == s2[index]) {
            ++index;
        }
        return s1.substr(0, index);
    }
};
```

```
["flower","flow","flight"]
        ↓
LCP("flower", "flow") = "flow"     ← 前4个字符都相同
        ↓
LCP("flow", "flight") = "fl"       ← 第3个字符 o≠i，停
        ↓
结果："fl"
```

**时间复杂度**：O(n × m)，最坏情况所有字符串都相同

## 方法二：纵向扫描（与我的解法相同）

官方也提供了纵向扫描，思路和我的解法完全一致：逐列比较所有字符串的同一位置。

> 我的解法本质上就是**官方纵向扫描解法**，只是用 `bool back` 替代了直接 `return`。

## 方法三：分治

将字符串数组分成左右两半，分别求 LCP，再合并两个 LCP。

```
["flower","flow","flight","flask"]
              ↓ 分
["flower","flow"]  ["flight","flask"]
       ↓ LCP              ↓ LCP
      "flow"             "flas"
              ↓ 合并 LCP
             "fl"
```

**时间复杂度**：O(n × m)，但递归有栈开销

## 方法四：二分查找

对**公共前缀的长度**进行二分查找。最长公共前缀的长度范围是 `[0, minLen]`，每次取中间值 `mid`，判断所有字符串的前 `mid` 个字符是否相同。

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";

        // 找最短长度作为二分上界
        int minLen = INT_MAX;
        for (const string& s : strs)
            minLen = min(minLen, (int)s.size());

        int lo = 0, hi = minLen;
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (isCommonPrefix(strs, mid))
                lo = mid;     // 前 mid 个字符相同 → 尝试更长
            else
                hi = mid - 1; // 不同 → 缩短
        }
        return strs[0].substr(0, lo);
    }

    bool isCommonPrefix(const vector<string>& strs, int len) {
        string prefix = strs[0].substr(0, len);
        for (int i = 1; i < strs.size(); ++i) {
            if (strs[i].find(prefix) != 0)  // 第 i 个字符串不以 prefix 开头
                return false;
        }
        return true;
    }
};
```

**时间复杂度**：O(n × m × log m)，二分 log m 次，每次判断 O(n × m)

# 四种解法对比

| 解法 | 思路 | 时间复杂度 | 空间复杂度 | 面试推荐 |
|------|------|-----------|-----------|---------|
| **纵向扫描（我的）** | 逐列比较所有字符串 | O(n × m) | O(1) | ✅✅ 最推荐 |
| **横向扫描** | 两两求 LCP，逐步缩小 | O(n × m) | O(1) | ✅✅ 很直观 |
| **分治** | 递归分半再合并 | O(n × m) | O(m × log n) | ✅ 展示分治思想 |
| **二分** | 二分前缀长度 | O(n × m × log m) | O(1) | ✅ 展示二分思想 |

> [!tip] 面试时推荐哪种？
> **纵向扫描**（我的解法）或**横向扫描**——代码最短、思路最清晰、最不容易写错。
> 分治和二分适合面试官追问"还有别的方法吗？"时展示思维广度。

# 关键洞察

> [!tip] 为什么我的解法和官解纵向扫描等价？
>
> 官方纵向扫描用 `return` 直接退出方法，我的解法用 `bool back` 跳出两层循环——**控制流不同，但逻辑完全一致**。
>
> 如果想更简洁，可以把 `back` 改成 `return`：
> ```cpp
> for (int i = 0; i < min_size; ++i) {
>     char ch = strs[0][i];
>     for (string s : strs)
>         if (s[i] != ch)
>             return ans;  // 直接返回，不需要 back 变量
>     ans += ch;
> }
> return ans;
> ```
