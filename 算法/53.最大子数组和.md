# 初见
一开始不知道该怎么写，但是脑子中出现的第一感觉是前缀和，虽然我也不是很清楚前缀和究竟哪里好，后面看提示有动态规划，然后就开始往那个思路开始靠。突然想到一个思路：我设计一个dpm用于存i位值最大的连续和的值，如果该值小于0，那么下一个值的连续值最大就是它本身，如果它大于0，那么第i+1位最大的连续和就需要加上它，这样求得最大的值就行
```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        vector<int> dpm(nums.size());//创建一个nums长度的dp，用来存储每一步的连续最大
        if(nums.size()==1)
        return nums[0];
        dpm[0]= nums[0];
        int max=INT_MIN;
        max=nums[0];
        for(int i=1;i<nums.size();++i)
        {
            if(dpm[i-1]<0)//连续和已经小于0
            dpm[i]=nums[i];
            else
            dpm[i]=dpm[i-1]+nums[i];
            if(dpm[i]>max)
            max=dpm[i];
        }   
        return max;
    }
};
```
# 官方题解
## 1.动态规划
```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int pre = 0, maxAns = nums[0];
        for (const auto &x: nums) {
            pre = max(pre + x, x);
            maxAns = max(maxAns, pre);
        }
        return maxAns;
    }
};
```
这个思路和我的思路差不多，但是我多了个非负判断，实际上应该不需要
这个算法的时间复杂度是O(n)，空间复杂度是O（1）
