# 解法一

递归到最后的节点之后对count进行++操作，最后如果count=n+1则进行删除操作(找到倒数第n个节点的前一个节点)，如果在此之前遍历到了头节点，那么就需要删除头节点（直接将new_head移向下一个节点）
# 解法二
第二种方法就是非常朴实无华的操作，先遍历一遍链表，求取链表的总长度，之后根据倒数第几个节点求取需要操作的节点就好了（不过答案实际上创建了一个空表头，这个能够统一删除操作，还是很有用的，而且实际上我忘记了对相应的节点进行delete操作）
# 解法三
这个解法使用了栈，遍历链表的同时将所有节点放入栈，依据先入后出的特点，可以找到倒数第n个节点，并且当前栈顶部的节点就是它的前驱节点（如果为头节点，则前驱节点实际上是空表头）
