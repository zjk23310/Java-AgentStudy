# 答案
再看一遍感觉答案给的思路依旧是比较精彩的
首先就是定义dp数组，dp\[0\]为true，dp表示该下标能否被wordDict的字符串来表示，那么接下来的问题在于怎么去确定每个dp的值呢？
答案采用了双重循环的方式，第一层循环来遍历整个字符串，第二层遍历则是为了~={red}根据前面的动态dp的值来判断是否能够在第一层的基础上找到新的dp为true的值=~
~={orange}其实就是考虑如下事情：在第一层的每个i，我前面的dp都已经确定了，但是实际上当i向后移动时，我的dp[i]并不确定，那么这时就要对dp[i]进行寻找了，并且这里还有类似于剪枝的思想，我只需要确定dp[i]为真就好，而不需要知道有多少个，多以如果找到则可以直接break=~
```cpp
class Solution {
public:
    bool find(string s,unordered_set<string>&map)
    {
        if(map.count(s))
            return true;
        else
         return false;
    }

        bool wordBreak(string s, vector<string>& wordDict) {
            unordered_set<string>map;
            for(string i:wordDict)
            map.insert(i);
            vector<bool> dp(s.size()+1);
            dp[0]=true;
            for(int i=0;i<=s.size();++i)
               for(int j=0;j<i;++j)
                {
                    if(dp[j]&&find(s.substr(j,i-j),map))
                       {dp[i]=true;
                       break;}
                }
            return dp[s.size()];
        }
};
```
