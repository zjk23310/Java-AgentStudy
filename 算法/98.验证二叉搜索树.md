# 初见
这一题思路和答案几乎一样，就是使用递归判断左右子树是否满足二叉搜索树的条件，但是一开始我没有考虑到有上下界的问题（这个意思是，实际上右子树存在下界，它的左子树的节点值要大于根节点的根节点的值，同样左字数存在上界，它的右子树的节点值要小于根节点的节点值，那么一开始我没有考虑到这个问题，我的代码是怎样的呢？
```cpp
class Solution {
public:

    bool check(TreeNode* root, int parentVal,bool left,int edge)//创建一个界限，右子树的左节点不能比根节点要小，左子树的右节点不能比根节点要大
    {
        if (root == nullptr)
            return true;
        bool isValid = true;
        if (left)//检查左子树
        {
            if (root->val >= parentVal||root->val<=edge)
                isValid = false;

        }
        else {
            if (root->val <= parentVal||root->val>=edge)//右子树该节点的值要确保不比边界值要大
                isValid = false;
        }
        bool Left= check(root->left, root->val, true,);
        bool Right= check(root->right, root->val, false);
        return Left && Right && isValid;
    }
        bool isValidBST(TreeNode* root) {
        return check(root, root->val+1, true);
    }
};
```
这是我的代码（代码并不完整也不正确），当时我的想法是使用一个标志位left来判断现在遍历的是左子树还是右子树，从而与根节点进行比较，但是我这样写实际上是有问题的，就是我的edge实际上只是一个边界，不是上下界这种可以对比的关系，这个edge边界就不是能很好地被利用，所以就有了官解的答案：使用上下界限的方式来解决这一问题：
```cpp
class Solution {
public:
    bool helper(TreeNode* root, long long lower, long long upper) {
        if (root == nullptr) {
            return true;
        }
        if (root -> val <= lower || root -> val >= upper) {
            return false;
        }
        return helper(root -> left, lower, root -> val) && helper(root -> right, root -> val, upper);
    }
    bool isValidBST(TreeNode* root) {
        return helper(root, LONG_MIN, LONG_MAX);
    }
};
```
~={yellow}这个问题的解决方案也就从：看父母节点的值转变成了根据上下界限解决问题=~
# 中序遍历-迭代方式
这时另一种方法，主要是使用到了二叉搜索树的性质，使用中序遍历后得到的是一个有顺序的数组，那么就可以先对二叉树进行遍历，之后再遍历这个数组就好了
```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        stack<TreeNode*> stack;
        long long inorder = (long long)INT_MIN - 1;

        while (!stack.empty() || root != nullptr) {
            while (root != nullptr) {
                stack.push(root);
                root = root -> left;
            }
            root = stack.top();
            stack.pop();
            // 如果中序遍历得到的节点的值小于等于前一个 inorder，说明不是二叉搜索树
            if (root -> val <= inorder) {
                return false;
            }
            inorder = root -> val;
            root = root -> right;
        }
        return true;
    }
};
```
需要注意，这里并没有使用递归的方式去中序遍历二叉搜索树，而是使用迭代的方式（使用栈）去遍历
