## 主要思想：
其实就是将每一步的和存入哈希表，如果该和减去target在哈希表中能够找到则说明，在这个区间存在连续的和为target。从0下标到最后下标即可
官解给的是使用map，但是我想能不能使用set呢？毕竟都需要查询是否在集合中，但是仔细想想的话实际上是不行的，思考如下情况：~={red}某些情况下，我的前缀和减去target会出现多次比如{1，-1，0}的情况，这种情况下，我无法记录之前出现的次数，所以需要使用有值的map集合=~
``` c++
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> mp;
        mp[0] = 1;
        int count = 0, pre = 0;
        for (auto& x:nums) {
            pre += x;
            if (mp.find(pre - k) != mp.end()) {
                count += mp[pre - k];
            }
            mp[pre]++;
        }
        return count;
    }
};
```
