给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

`int dfs(vector<int>&nums,int curr,int target,int i)

    {

        if(i==0)

        return 0;

        int ret=0;

        if(curr==target)

            ret+=1;

        ret+=dfs(nums,curr+nums[i-1],target,i-1);

        ret+=dfs(nums,curr,target,i-1);

        return ret;

    }

    bool canPartition(vector<int>& nums) {

        int sum=0;

        for(int i:nums)

        sum+=i;

        if(sum%2!=0)

        return false;

        return dfs(nums,0,sum/2,nums.size());

    }`
