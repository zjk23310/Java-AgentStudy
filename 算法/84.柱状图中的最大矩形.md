# 解答
常规解法使用了两层循环，这个时候算法的时间复杂度实际上是O（n^2)，但是如果使用单调栈，确定每个位置的上下界，时间复杂度各为O（n），并且之后进行乘法运算也只需要遍历n长度的数组大小，所以可知总的时间复杂度为O(n),由于我们定义了长度为n的up和down，以及栈（栈的空间还是难以确定的，但它的最大空间不超过n，所以我们就实现了时间和空间复杂度都为O(n)的算法

## 单调栈加常数优化

![[84.柱状图中的最大矩形-1777189143717.webp]]
这个就很想之前提到过的每日温度问题了，但是又有所不同，感觉可以仔细体会一下之间的异同
```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        vector<int> left(n), right(n, n);
        
        stack<int> mono_stack;
        for (int i = 0; i < n; ++i) {
            while (!mono_stack.empty() && heights[mono_stack.top()] >= heights[i]) {
                right[mono_stack.top()] = i;
                mono_stack.pop();
            }
            left[i] = (mono_stack.empty() ? -1 : mono_stack.top());
            mono_stack.push(i);
        }
        
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            ans = max(ans, (right[i] - left[i] - 1) * heights[i]);
        }
        return ans;
    }
};
```
