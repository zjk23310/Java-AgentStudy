## 单指针
我们可以考虑对数组进行两次遍历。在第一次遍历中，我们将数组中所有的  交换到数组的头部。在第二次遍历中，我们将数组中所有的  交换到头部的  之后。此时，所有的  都出现在数组的尾部，这样我们就完成了排序。
具体地，我们使用一个指针  表示「头部」的范围， 中存储了一个整数，表示数组  从位置  到位置  都属于「头部」。 的初始值为 ，表示还没有数处于「头部」。
在第一次遍历中，我们从左向右遍历整个数组，如果找到了 ，那么就需要将  与「头部」位置的元素进行交换，并将「头部」向后扩充一个位置。在遍历结束之后，所有的  都被交换到「头部」的范围，并且「头部」只包含 。
在第二次遍历中，我们从「头部」开始，从左向右遍历整个数组，如果找到了 ，那么就需要将  与「头部」位置的元素进行交换，并将「头部」向后扩充一个位置。在遍历结束之后，所有的  都被交换到「头部」的范围，并且都在  之后，此时  只出现在「头部」之外的位置，因此排序完成
```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int ptr = 0;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 0) {
                swap(nums[i], nums[ptr]);
                ++ptr;
            }
        }
        for (int i = ptr; i < n; ++i) {
            if (nums[i] == 1) {
                swap(nums[i], nums[ptr]);
                ++ptr;
            }
        }
    }
}
```
## 双指针1
这里采用p0指向0元素，p1指向1的位置，遍历整个数组，如果数组元素为1则与p1指向位置交换并且p1加一，若为0则与p0位置交换，并且p0,p1都需要加一
![[75.颜色分类-1777258663247.webp]]
```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int p0 = 0, p1 = 0;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 1) {
                swap(nums[i], nums[p1]);
                ++p1;
            } else if (nums[i] == 0) {
                swap(nums[i], nums[p0]);
                if (p0 < p1) {
                    swap(nums[i], nums[p1]);
                }
                ++p0;
                ++p1;
            }
        }
    }
};
```
## 双指针2
方法和方法二类似，但是有所区别的地方在于，i遍历超过p2的时候就已经结束操作了，能够降低时间操作。
![[75.颜色分类-1777258729616.webp]]
```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int p0 = 0, p1 = 0;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 1) {
                swap(nums[i], nums[p1]);
                ++p1;
            } else if (nums[i] == 0) {
                swap(nums[i], nums[p0]);
                if (p0 < p1) {
                    swap(nums[i], nums[p1]);
                }
                ++p0;
                ++p1;
            }
        }
    }
};

```
由于本题的算法比较简单，所以实际上基本看不出什么时间差距，但是使用排序算法其实是一个比较耗时的操作
