给定一个含有 n 个正整数的数组和一个正整数 s ，找出该数组中满足其和 ≥ s 的长度最小的 连续 子数组，并返回其长度。如果不存在符合条件的子数组，返回 0。
**这里需要注意的是子序列还有子数组的区别，子数组要求连续，子序列不要求连续，所以我一开始的排序从最大处的思路是错误的**
示例：

输入：s = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。
提示：

1 <= target <= 10^9
1 <= nums.length <= 10^5
1 <= nums[i] <= 10^5

>注意:这里的滑动窗口的思想是:从下标0开始,记录两个下标分别为left,right.当left和right之间的和大于等于target就需要进行窗口滑动操作,移除窗口左边的元素直到和小于target然后再次移动right知道和大于等于target
