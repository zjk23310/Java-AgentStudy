这题使用二叉树的层序遍历，每次都把该层的第一个值记录就好了，最后返回最后一层的第一个值就是答案。不过使用这种方法提交之后的时间效率并不是很高。大概只超越了22%。可能是因为我向队列中的push和pop操作耗时了。

那么则这一题可以使用递归吗？可以的
# 递归写法
我该怎么找到最后一层的元素，并且找到第一个元素呢？如果一直向左遍历可以找到最左边的节点，但是有个致命的问题是该节点可能不是最深的。所以可能还需要另一个参数，这里使用的是一个全局变量maxDepth，如果遍历的深度超过了最大深度就是要记录的新的值
那有人可能就要疑惑了，尽管这样，我怎么知道记录的是最左边的值呢？这就与遍历的顺序有关了。因为先遍历的左子树。
```c++
class Solution {
public:
    int maxDepth = INT_MIN;
    int result;
    void traversal(TreeNode* root, int depth) {
        if (root->left == NULL && root->right == NULL) {
            if (depth > maxDepth) {
                maxDepth = depth;
                result = root->val;
            }
            return;
        }
        if (root->left) {
            traversal(root->left, depth + 1); // 隐藏着回溯
        }
        if (root->right) {
            traversal(root->right, depth + 1); // 隐藏着回溯
        }
        return;
    }
    int findBottomLeftValue(TreeNode* root) {
        traversal(root, 0);
        return result;
    }
};
```
