这一题还是比较简单的，就是需要注意这一题让你求到叶子节点的，而不是所有路径的，如果是这样就需要判断该节点是不是叶子节点，如果是叶子节点则进行另外的判断
简单代码如下：
```c++
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if(root==nullptr)
            return false;
        if(root->left==nullptr&&root->right==nullptr)
        {
            if(targetSum-root->val==0)
            return true;
            else
            return false;
        }
        bool Left= hasPathSum(root->left,targetSum-root->val);
        bool Right= hasPathSum(root->right,targetSum-root->val);
        return Left||Right;
    }
};
```
这题也可以用迭代法，迭代法也就是bfs，存的是一个par类型，第二个值标识从根节点到现在节点的所有和的值，如果该节点是叶子节点则进行比较。
