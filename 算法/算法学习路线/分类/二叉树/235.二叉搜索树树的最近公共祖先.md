[[236.二叉树的最近公共祖先]]

236是一个普通的二叉树最近公共祖先问题，这道题我们使用了后续遍历的方式处理。相较于上一题，这一题的二叉树是一个搜索树。二叉搜索树是有序的，那么如何利用这一点就成了做题的关键。这一题倒是可以不需要使用中序遍历回溯之类的，可以直接使用递归来写
具体代码如下：
```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root->val > p->val && root->val > q->val) {
            return lowestCommonAncestor(root->left, p, q);
        } else if (root->val < p->val && root->val < q->val) {
            return lowestCommonAncestor(root->right, p, q);
        } else return root;
    }
};
```
这个算法还是很妙的，巧妙地运用了二叉搜索树的性质
当然也可以使用迭代法
```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        while(root) {
            if (root->val > p->val && root->val > q->val) {
                root = root->left;
            } else if (root->val < p->val && root->val < q->val) {
                root = root->right;
            } else return root;
        }
        return NULL;
    }
};
```
不过令我比较好奇的地方在于：这些方法的时间都没有236的方法执行的时间短，而且是应用迭代反而慢了，也算是比较奇怪的地方了。但是我想可能是由于使用了root->val这种吧，而直接使用236时只需要比较节点是否相同。
