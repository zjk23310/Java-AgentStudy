# 二叉树
## 二叉树的递归遍历
主要需要了解二叉树如何使用递归进行简单的遍历，这个问题是十分简单的.

## 二叉树的迭代遍历
二叉树的迭代遍历需要使用到栈作为中间存储节点的工具，其中前序遍历的方式是最简单的。中序遍历则是最复杂的，后序遍历可以确定存入栈的方向，出栈后进行反转操作就能够得到答案。但是这样遍历有一个显而易见的缺点：遍历的方式不够统一，为了得到一个能够统一使用的方法，这显然是不符合我们想法的

## 二叉树的统一迭代
```c++
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        if (root != NULL) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != NULL) {
                st.pop(); // 将该节点弹出，避免重复操作，下面再将右中左节点添加到栈中
                if (node->right) st.push(node->right);  // 添加右节点（空节点不入栈）

                st.push(node);                          // 添加中节点
                st.push(NULL); // 中节点访问过，但是还没有处理，加入空节点做为标记。

                if (node->left) st.push(node->left);    // 添加左节点（空节点不入栈）
            } else { // 只有遇到空节点的时候，才将下一个节点放进结果集
                st.pop();           // 将空节点弹出
                node = st.top();    // 重新取出栈中元素
                st.pop();
                result.push_back(node->val); // 加入到结果集
            }
        }
        return result;
    }
};
```

这里有该代码的示意图，实际上本质就是按照对应的顺序将节点放入到栈中。但是在放入栈中的时候还要再对应位置放入Null进行标识，当弹出null的时候就知道要将该节点的值放入结果集了。
那么前序遍历应该怎么做呢？
```c++
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        if (root != NULL) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != NULL) {
                st.pop();
                if (node->right) st.push(node->right);  // 右
                if (node->left) st.push(node->left);    // 左
                st.push(node);                          // 中
                st.push(NULL);
            } else {
                st.pop();
                node = st.top();
                st.pop();
                result.push_back(node->val);
            }
        }
        return result;
    }
};
```
这里值改变了push(node)还有push(null)的位置，这个代码第一眼比较复杂，不知道为什么，但是如果理解它的原理（也就是为了知道在什么位置我们应该加入结果集需要加入null节点），这个方法还是能够很好地将三种方法统一起来的
