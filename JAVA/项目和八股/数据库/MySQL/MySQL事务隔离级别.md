# 事务隔离级别
事务隔离级别可以有多种：
读未提交、读已提交、可重复读、可串行化
有关事务的隔离级别我觉得只要想到两个事务的场景，这部分内容就比较好理解，可以不被概念，可能需要注意的是什么是幻读
以及行级锁和间隙锁是什么。
