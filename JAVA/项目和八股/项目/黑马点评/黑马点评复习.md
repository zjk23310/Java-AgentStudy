# 登录流程
登录流程主要有
1. /user/me
2. /user/code
3. /user/login
这里/me接口简单，主要返回的是用户昵称、头像之类的，主要用户前端页面的用户展示。
如果这里没有用户信息（也就是userholder中的getuser为空）就会跳转到登录界面
在继续推进之前，必须先说明userholder是如何获取user的，这里涉及到双拦截器（如果对拦截器相关知识不了解移步到SSM）
