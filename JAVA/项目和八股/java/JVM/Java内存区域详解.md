# 运行时数据区域
## 线程私有
程序计数器、虚拟机栈、本地方法栈
### 程序计数器
了解程序计数器是什么
特征在于线程私有，内存空间较小
了解程序计数器的**两个功能**：- 用于实现流程控制（顺序、选择、循环） - 多线程情况下可记录当前程序执行的位置
程序计数器**生命周期**随线程完全同步

### Java虚拟机栈
有个重要概念：栈帧
每一次方法调用都会有一个对应的栈帧被压入栈中，每一个方法调用结束后，都会有一个栈帧被弹出。
每个栈帧中都拥有：局部变量表、操作数栈、动态链接、方法返回地址
