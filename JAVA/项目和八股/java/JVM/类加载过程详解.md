# 类的生命周期
简单概括可以分为7个阶段：
加载、验证、准备、解析、初始化、使用、卸载
其中验证、准备、解析三个阶段统称为连接
## 加载
加载主要完成：
1.通过全类名获取定义此类的二进制字节流
2.将字节流所代表的静态存储结构转换为方法区的运行时数据结构
3.在内存中生成一个代表该类的Class对象，作为方法去这些数据的访问入口
加载主要通过类加载器万层。类加载器有多种，可以参考[[Java类加载器详解]]
加载阶段和连接阶段的部分动作是交叉进行的，加载阶段未结束连接阶段就可能开始了

## 验证
验证是连接阶段的第一步。验证阶段主要由四个检验阶段组成
1.文件格式验证 Class文件格式检查
2.元数据验证 字节码语义检查
3.字节码验证 程序语义检查
4.符号引用验证 类的正确性检查

## 准备
准备阶段是正式为类变量分配内存并设置变量初始值的阶段，这些内存都将在方法区中被分配
需要注意以下问题：1.这时分配仅包括类变量不包含实例变量（实例变量会在对象实例化时随对象一起被分配在Java堆上）
2.类变量所使用的内存应该全部在方法区中进行分配
3.这里设置的初始值通常是数据类型的默认零值

## 解析
解析是虚拟机从运行时常量池中的符号引用动态确定具体值的过程

## 初始化
初始化阶段会执行类或接口的初始化方法，这是类加载过程的最后一步

## 类使用与类卸载
类使用就是加载完成之后使用类，类的卸载则是JVM回收某个类或接口的方法区表示以及关联资源的过程。
类或接口只有在其定义类加载器可被垃圾回收时才可能卸载。由启动类加载器定义的类或接口不能卸载。
在HotSpot中判断某个类是否可能卸载需要从以下条件理解：
1.该类的所有实例对象都已经被GC，堆中不存在该类的实例对象
2.该类没有在其他任何地方被引用
3.该类的类加载器的实例已经被GC
